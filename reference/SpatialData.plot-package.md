# SpatialData.plot: SpatialData visualization

Visualization suit for 'spatialdataR'. Current functionality includes
handling of multiscale 'images', visualizing 'labels', 'points', and
'shapes'. For the latter, POINT, POLYGON, and MULTIPOLYGON geometries
are supported. For all but 'images', there is support to pass
information from annotation 'tables' as aesthetics (e.g., 'colData' or
'assay' data).
